# Icons

Generated — do not edit by hand. From the repo root run:

```bash
pnpm icons   # tauri icon ../../assets/branding/app-icon.png
```

Use a 1024×1024 master PNG. The generated `icon.ico` embeds 16–256 px layers and
`icon.icns` embeds up to 1024 px, satisfying the 256×256 high-res requirement for
`.exe` / `.app`.
