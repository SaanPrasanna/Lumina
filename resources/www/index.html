It works — Lumina is running.

Your local development environment: web servers, PHP, databases and a real domain for every project, managed from one fast, native app.

Get started

  1. 1

    Add a project folder next to this page.
    A folder named blog is served at http://blog.test — Lumina writes the virtual host and the hosts entry for you.

  2. 2

    Pick your stack on the Services page.
    nginx or Apache, any installed PHP version, MySQL or MariaDB, and Redis — switch in one click.

  3. 3

    Connect to the database at 127.0.0.1 as root, no password.
    The port is shown on the Services page.

Everything your local stack needs, in one app

Lightweight, native and open source — built in Rust for Windows, macOS and Linux.

nginx & Apache

Configs are tested before they are applied, and a reload works on the first try. A broken config is rolled back, never left running.

Every PHP version

Keep several PHP versions side by side and switch in a click. Old workers are stopped and verified gone — no ghost processes.

MySQL, MariaDB & Redis

Ready on first start with no setup, sized to your computer's memory, and shut down cleanly so your data stays safe.

Automatic .test domains

Every folder becomes its own site. Laravel's public/ and Symfony's web/ are detected; the hosts file is updated for you.

Port conflicts, solved

When a port is taken, Lumina names the program holding it and moves your service to a free port in one click.

Quiet in the tray

Start and stop everything from the tray. On exit every service is stopped — nothing keeps running behind your back.
