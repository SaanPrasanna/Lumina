Your projects

One folder, one site.

Every folder next to this page becomes a site. Lumina writes its server config and hosts entry and gives it a trusted certificate. Laravel's public/ is found on its own; Vite, Next.js, Nuxt, Django and FastAPI projects run behind their own dev server. New projects can also be created with QuickApp.

www/
├── index.html      this page
├── blog/           → https://blog.test
└── shop/public/    → https://shop.test

Connections

Default addresses for apps and database clients.

Service Address User Password
MySQL, MariaDB 127.0.0.1:3306 root none
PostgreSQL 127.0.0.1:5432 postgres none
Redis 127.0.0.1:6379 – none
MongoDB 127.0.0.1:27017 – none
Mail (SMTP) 127.0.0.1:1025 any any

Ports can be changed in Settings. Services are installed from Quick Add and started on the Services page.

Tools

Available once installed.

  • /adminer/MySQL, MariaDB, PostgreSQL and SQLite
  • /phpmyadmin/MySQL and MariaDB
  • localhost:8025Mailpit inbox for mail your sites send

Also in Lumina

Versions side by side
PHP, Node.js, Python, Bun and Deno, plus servers and databases, each download checked first. A PHP version per site.
Debugging
Xdebug in one switch, the latest requests of every site, and a webhook catcher that replays.
Snapshots
Save a MySQL, MariaDB or PostgreSQL database before a migration and restore it in one click.
Sharing
A public HTTPS address through Cloudflare Tunnel or ngrok, or your sites on phones on the same Wi-Fi.
