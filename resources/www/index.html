Web server running

It works — Lumina is running. Your local web server and PHP are up. Here is how to get going.

  1. Create a project folder next to this page.
    A folder named blog opens at http://blog.test — no setup needed.

  2. Start a Laravel app in this folder: composer create-project laravel/laravel blog Lumina serves its public/ folder automatically.

  3. Connect to the database at 127.0.0.1 as root with no password.
    The port and engine (MySQL or MariaDB) are on Lumina's Services page.
