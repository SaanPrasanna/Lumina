Get started

  1. 1

    Add a project

    Put a folder next to this page. A folder named blog opens at http://blog.test; Lumina writes its site and hosts entry for you. Or create one with QuickApp.

  2. 2

    Choose your stack

    On the Services page: nginx or Apache, any installed PHP version, MySQL or MariaDB, PostgreSQL and Redis. Install more versions from Quick Add.

  3. 3

    Connect to a database

    MySQL and MariaDB: root at 127.0.0.1, no password. PostgreSQL: postgres, no password. The ports are on the Services page.

What Lumina does for you

Fast to start, quiet in the background, and nothing left running when you quit.

  • Automatic sites

    Every folder becomes folder.test. Laravel's public/ and similar folders are found on their own.

  • Trusted HTTPS

    A certificate authority that exists only on your computer gives every site a padlock your browsers trust.

  • Quick Add

    Install and switch versions of PHP, servers, databases, Node.js and Python. Every download is checked first.

  • QuickApp

    Laravel, WordPress, Symfony, Drupal and more in one click, with the database created and the site ready.

  • Profiles

    Save stacks like "nginx · PHP 8.3 · MySQL 8.4" and switch between them in one click.

  • Share a site

    Put a site on a public HTTPS address through ngrok, with a QR code for your phone.
