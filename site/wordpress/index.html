WordPress on your own computer

Build themes and plugins against a real WordPress install, with a proper address, HTTPS and every outgoing mail caught locally.

Download Lumina, free View on GitHub

A new site in one click

QuickApp › WordPress downloads WordPress and creates its database, so the site is ready at https://name.test.

What WordPress gets

  • PHP 7.4 to 8.5 per site, so old and new sites run side by side.
  • Apache (with .htaccess permalinks) or nginx, MySQL or MariaDB.
  • Mail from wp_mail() lands in Mailpit, no SMTP plugin needed.
  • phpMyAdmin and Adminer, database snapshots, and a public link to show a client.

Questions

Can I move an existing site in?

Yes. Copy its folder into www, import the database with phpMyAdmin, and update siteurl and home (for example with WP-CLI search-replace).

Is it an alternative to Local?

Yes, and it is not limited to WordPress. See Lumina vs Local.

Guides

  • Catch Laravel mail locally with Mailpit

    Send every email from your local Laravel or PHP app to a local Mailpit inbox instead of real people, with the .env settings to use.

  • Local .test domains on Windows

    Give every local project its own address like http://blog.test on Windows, without editing the hosts file or Apache virtual hosts by hand.

  • Trusted HTTPS for localhost

    Get https://localhost and https://project.test with a padlock and no browser warning, using a certificate authority that exists only on your computer.
