Local PHP development, set up in minutes

Lumina runs real PHP, a web server and a database on your own computer, with no Docker and no virtual machine. Every project gets its own address and the PHP version it needs.

Download Lumina, free View on GitHub

What you get

  • PHP 7.4 to 8.5 as FastCGI, side by side, one version per site if you like.
  • nginx or Apache, MySQL or MariaDB, PostgreSQL and Redis, started with one click.
  • php and composer in every terminal, following the active version.
  • Xdebug in one switch, Mailpit for outgoing mail, phpMyAdmin and Adminer for databases.
  • Every folder in www at https://folder.test with a trusted certificate.

Get started

  1. Download and install Lumina.
  2. In Quick Add, install PHP, a web server and a database.
  3. Press Start All and open http://localhost: the welcome page lists every database login.

Questions

Is Lumina free?

Yes, open source under the GNU GPL v3.0, with no paid edition.

Can I use Apache .htaccess files?

Yes, choose Apache as the web server and .htaccess works as on most shared hosting.

Guides

  • Run PHP 7.4 and PHP 8.4 side by side on Windows

    How to run several PHP versions on Windows at the same time, PHP 7.4 to 8.5, and give each project its own version, without editing Apache or nginx configs by hand.

  • Local .test domains on Windows

    Give every local project its own address like http://blog.test on Windows, without editing the hosts file or Apache virtual hosts by hand.

  • Trusted HTTPS for localhost

    Get https://localhost and https://project.test with a padlock and no browser warning, using a certificate authority that exists only on your computer.
