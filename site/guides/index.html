Guides

Short, practical guides for running web projects on your own computer with Lumina.

How to

  • Run PHP 7.4 and PHP 8.4 side by side on Windows

    How to run several PHP versions on Windows at the same time, PHP 7.4 to 8.5, and give each project its own version, without editing Apache or nginx configs by hand.

  • Run Laravel locally with HTTPS

    Set up a Laravel project locally with a real https:// address and a certificate your browser trusts, plus MySQL and Mailpit, on Windows, macOS or Linux.

  • Local .test domains on Windows

    Give every local project its own address like http://blog.test on Windows, without editing the hosts file or Apache virtual hosts by hand.

  • Trusted HTTPS for localhost

    Get https://localhost and https://project.test with a padlock and no browser warning, using a certificate authority that exists only on your computer.

  • Run Next.js, Vite or Django at a local domain

    Serve Next.js, Nuxt, Vite, SvelteKit, Django, FastAPI or Flask dev servers at https://project.test instead of localhost:3000, with hot reload.

  • Catch Laravel mail locally with Mailpit

    Send every email from your local Laravel or PHP app to a local Mailpit inbox instead of real people, with the .env settings to use.

By stack

  • Local PHP development, set up in minutes

    A free local PHP environment: PHP 7.4 to 8.5 side by side, nginx or Apache, MySQL, PostgreSQL and Redis, Composer and Xdebug, with .test sites and trusted HTTPS.

  • Laravel, locally, with everything included

    Run Laravel locally with PHP 8.4, nginx, MySQL or PostgreSQL, Redis and Mailpit, at https://app.test, on Windows, macOS and Linux. Free and open source.

  • WordPress on your own computer

    Run WordPress locally at https://site.test with PHP, MySQL, Apache or nginx and Mailpit, on Windows, macOS and Linux. Free and open source.

  • Node.js projects at their own local domain

    Install Node.js versions side by side and serve Next.js, Vite, Nuxt, Astro or SvelteKit dev servers at their own https://name.test address, with hot reload.

  • Python projects at their own local domain

    Install Python versions side by side and serve Django, FastAPI or Flask dev servers at their own https://name.test address, with PostgreSQL and Redis next to them.
