Run Next.js, Vite or Django at a local domain

localhost:3000, localhost:5173, localhost:8000: ports collide and cookies leak between projects. Lumina puts each dev server behind its own https://name.test address and keeps hot reload working.

Download Lumina, free View on GitHub

Supported out of the box

A folder in www with Vite, Next.js, Nuxt, Astro, SvelteKit or React Router (and no PHP), or with Django, FastAPI or Flask, is recognised and served by its own dev server. Any other command works too: Edit › Served by.

Start it

  1. Install Node.js or Python from Quick Add, and a web server.
  2. Put the project in www, for example www\storefront.
  3. On Sites, press Start on its row. Lumina runs the dev server on a fixed port and shows its log.
  4. Open https://storefront.test. Saving a file reloads the page as usual.

The right runtime version

A project's .nvmrc, .node-version, .python-version or .tool-versions picks the Node.js or Python version its dev server runs with, from the versions installed in Quick Add.

Questions

Can the dev server start with Start All?

Yes, switch on autostart for it in Edit.

Does it work with pnpm, Bun or uv?

Yes. Bun, Deno, uv and pnpm are in Quick Add and on PATH in every terminal.
