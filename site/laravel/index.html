Laravel, locally, with everything included

Everything a Laravel app expects, on your own computer: PHP, Composer, a database, Redis for queues and cache, and Mailpit for mail, all free.

Download Lumina, free View on GitHub

A new project in one click

QuickApp › Laravel creates the project with Composer, makes its database, writes .env (database, mail to Mailpit) and opens it at https://name.test.

What Laravel gets

  • PHP 8.2 to 8.5 with the extensions Laravel needs, and Composer on PATH.
  • MySQL, MariaDB or PostgreSQL, and Redis for cache, queues and sessions.
  • Mailpit for every mail, Xdebug in one switch, database snapshots before a risky migration.
  • A public HTTPS link through Cloudflare Tunnel or ngrok for webhooks and demos.

Questions

Does it replace Laravel Herd or Valet?

It covers the same ground, including databases, Mailpit and Xdebug, for free, and runs on Linux too. See Lumina vs Herd.

Does Vite work?

Yes. Run npm run dev; Node.js comes from Quick Add.

Guides

  • Run Laravel locally with HTTPS

    Set up a Laravel project locally with a real https:// address and a certificate your browser trusts, plus MySQL and Mailpit, on Windows, macOS or Linux.

  • Catch Laravel mail locally with Mailpit

    Send every email from your local Laravel or PHP app to a local Mailpit inbox instead of real people, with the .env settings to use.

  • Run PHP 7.4 and PHP 8.4 side by side on Windows

    How to run several PHP versions on Windows at the same time, PHP 7.4 to 8.5, and give each project its own version, without editing Apache or nginx configs by hand.
