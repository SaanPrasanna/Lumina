Python projects at their own local domain

Python 3.10 to 3.14, uv, and Django, FastAPI or Flask served at https://name.test, next to PostgreSQL, MySQL and Redis.

Download Lumina, free View on GitHub

What you get

  • Python 3.10 to 3.14 from Quick Add, with pip and venv; uv too.
  • The version from .python-version or .tool-versions per project.
  • Django, FastAPI and Flask dev servers at https://name.test, with auto-reload.
  • PostgreSQL, MySQL, Redis and Mailpit with one click.

Get started

  1. Install Lumina, then Python and a web server from Quick Add.
  2. Put the project in www and press Start on its row in Sites.

Questions

Does it replace pyenv?

For Lumina's terminals and dev servers, yes: install versions in Quick Add and pick one per project with .python-version.

Guides

  • Run Next.js, Vite or Django at a local domain

    Serve Next.js, Nuxt, Vite, SvelteKit, Django, FastAPI or Flask dev servers at https://project.test instead of localhost:3000, with hot reload.

  • Trusted HTTPS for localhost

    Get https://localhost and https://project.test with a padlock and no browser warning, using a certificate authority that exists only on your computer.
