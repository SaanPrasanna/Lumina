Built for everyday development

Fast to start, quiet in the background, and out of your way.

  • One-click stack

    PHP with nginx or Apache, MySQL or MariaDB, PostgreSQL and Redis. Start All and Stop All from the app or the tray.

  • Automatic sites

    Every folder in your projects folder becomes folder.test. Lumina keeps the hosts file up to date.

  • Trusted local HTTPS

    A certificate authority that exists only on your computer gives every site a padlock your browsers trust.

  • Quick Add

    Install and switch versions of PHP, servers, databases, Node.js, Python and Composer. Every download is checked against its SHA-256. On macOS and Linux, PHP and the web servers come from Homebrew.

  • QuickApp

    Laravel, WordPress, Symfony, Drupal, Joomla and more in one click, with the database created and the site ready.

  • Profiles

    Save stacks like “nginx · PHP 8.3 · MySQL 8.4” and switch between them in one click.

  • Tray control panel

    A menu for each service: start or stop it, pick its version, open its config file or its log.

  • Share a site

    Put a site on a public HTTPS address through ngrok, with a QR code for your phone.

  • Signed updates

    Lumina updates itself. Every update is signed and verified first, and your services start again afterwards.

Up and running in minutes

  1. 1

    Install Lumina

    Download the installer for your system and run it. No administrator rights needed on Windows.

  2. 2

    Add your tools

    Open Quick Add and install PHP, a web server and a database, in the versions you need.

  3. 3

    Start building

    Press Start All, put a project in the www folder and open http://project.test.

Questions

Is Lumina free?

Yes. Lumina is open source under the GNU General Public License v3.0. There is no paid edition.

Do I need Docker or a virtual machine?

No. Lumina runs the real PHP, web server and database programs directly on your computer, so it starts fast and uses little memory.

Which PHP versions can I use?

On Windows, every version in Quick Add, side by side. On macOS and Linux, the versions you install with Homebrew (for example brew install php or php@8.3), which Lumina finds on its own. Switch with one click, per stack or per profile.

Can I use PostgreSQL and MySQL together?

Yes. PostgreSQL runs next to MySQL or MariaDB, each on its own port.

Where are my projects and databases kept?

In one data folder you choose on first start (C:\Lumina on Windows, ~/Lumina elsewhere). Uninstalling keeps it unless you ask otherwise.

Is it safe?

Services listen only on your own computer. Downloads are verified, updates are signed, and administrator rights are asked for only when they are needed.
