Lumina vs Laragon

Laragon made local PHP development on Windows fast and simple: every folder a .test site, Apache or nginx, MySQL, all from the tray. Recent versions need a paid license, and it still runs on Windows only. Lumina works the same way, stays free and open source, and runs on Windows, macOS and Linux.

Why developers switch from Laragon

  • Free, for good

    Lumina is GPL-3.0 open source with no paid edition, for personal and commercial work alike.

  • The same habits

    Folders in www become folder.test, Start All from the tray, a menu per service: it feels familiar from the first minute.

  • Beyond Windows and PHP

    The same stack on macOS and Linux, and Vite, Next.js or Django projects get their own .test address too.

Move your projects from Laragon

  1. Quit Laragon (Stop All, then Exit), so ports 80, 443 and 3306 are free.
  2. Install Lumina and add PHP, a web server and MySQL or MariaDB from Quick Add.
  3. Copy your project folders from C:\laragon\www to Lumina's www folder (C:\Lumina\www by default). They keep their folder.test addresses.
  4. Export your databases from Laragon (HeidiSQL, phpMyAdmin or mysqldump --all-databases) and import them in Lumina with phpMyAdmin, Adminer or mysql < dump.sql.

Questions

Is Lumina free like the old Laragon?

Yes. Lumina is open source under the GNU GPL v3.0. There is no license key, no paid edition and no limit on commercial use.

Can I run Laragon and Lumina at the same time?

Not with their default ports: both want ports 80, 443 and 3306. Stop one before you start the other, or change the ports in Lumina's Settings.

Do my Laragon projects work in Lumina?

Yes. They are ordinary folders. Copy them into Lumina's www folder and they get the same folder.test address; only the databases need to be exported and imported.
