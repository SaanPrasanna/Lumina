Lumina vs XAMPP

XAMPP is where many developers started: Apache, MariaDB and PHP in one installer. It is free, but every project lives at localhost/folder, there is one PHP version per install and HTTPS comes with a browser warning. Lumina keeps the one-installer simplicity and adds what modern projects need.

Why developers switch from XAMPP

  • A real address per project

    Every folder becomes https://folder.test, with a padlock your browser trusts. No httpd-vhosts.conf to edit.

  • Any PHP version, per site

    Keep an old project on PHP 7.4 and a new one on 8.5, side by side, without a second install.

  • More than Apache and MariaDB

    nginx, MySQL, PostgreSQL, Redis, MongoDB and Mailpit, plus Node.js and Python, each a click away in Quick Add.

Move your projects from XAMPP

  1. Stop Apache and MySQL in the XAMPP Control Panel, so ports 80 and 3306 are free.
  2. Install Lumina and add PHP, Apache or nginx, and MariaDB or MySQL from Quick Add.
  3. Copy your projects from C:\xampp\htdocs to Lumina's www folder. localhost/shop becomes https://shop.test; update the site URL in your app's settings (APP_URL, siteurl).
  4. Export each database with XAMPP's phpMyAdmin and import it with phpMyAdmin or Adminer in Lumina.

Questions

Is Lumina free like XAMPP?

Yes. Both are free and open source. Lumina is licensed under the GNU GPL v3.0.

Can I keep using Apache?

Yes. Choose Apache or nginx; Lumina writes the configuration for every site.

Will my WordPress site work after the move?

Yes. Update siteurl and home to the new https://folder.test address, for example with WP-CLI's search-replace.
